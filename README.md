# Budget Tracker

This is a full-stack budget tracking app I built for my final project. The goal was to create something that actually feels useful in real life, not just a demo app.

It lets you input your income, track expenses, and see where your money is going using charts.

---

## What it does

- Add income (weekly, biweekly, monthly, yearly)
- Automatically calculates estimated taxes + net income
- Add and delete transactions
- Categorize expenses (food, rent, etc.)
- Pie chart shows where your income is going (expenses + savings)
- Save and load budgets
- Filter transactions by month/year

---

## Tech used

- Frontend: React (Vite)
- Backend: Node.js + Express
- Database: PostgreSQL (Neon)
- Charts: Recharts
- Deployment:
  - Frontend: Vercel
  - Backend: Render
